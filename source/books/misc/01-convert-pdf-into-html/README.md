# Convert PDF into HTML


## For general PDFs: [PDF to HTML Converter](https://www.freeconvert.com/pdf-to-html)

## For slides: [pdf-webslides](https://github.com/misc0110/pdf-webslides)

1. cd to the directory where your PDF file is located
2. run the command:
```bash
    pdf-webslides -s your-file.pdf
```

无法居中，右侧会有黑边，链接会丢失
